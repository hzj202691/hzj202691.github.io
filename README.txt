=========================================
📁 这个文件夹用来存放你的学习资料文件
=========================================

使用方法：
1. 把你的 PDF、Word、PPT、代码等文件放在这个文件夹里
2. 然后在 data.js 里添加对应的信息即可

示例：
   files/
   ├── 高等数学复习笔记.pdf
   ├── Python入门教程.py
   ├── 项目源码.zip
   └── ...

注意：
- GitHub 单个文件最大 100MB
- 建议文件名用英文或拼音，避免中文乱码
- 大文件建议压缩成 zip
